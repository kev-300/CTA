# CTA
CTA (Control en la toma de Asistencia) es un proyecto universitario, busca eliminar el proceso 
repetitivo de transcripción de datos de formato físico a formato digital, esta pensado para uso empresarial
y de forma local, el proyecto esta basado con identificación biometrica con sensor de camara y de huella.
