Para ejecutar el programa se tienen que tener ciertos requisitos, por ahora solo funciona desde la terminal los archivos (Entrenamiento.py, captura.py y reconocimiento.py)
El sistema solo detecta rostros de forma local y su secuencia es (captura.py, Entrenamiento.py y reconocimiento.py)
El programa se esta ejecutando con Python 3.12, la libreria de Opencv es la 4.10 y se instala con el comando pip install opencv-contrib-python==4.10.0.84
Para las librerias como Pandas o Numpy se pueden ejecutar las versiones recientes sin problemas.
